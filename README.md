# NisonAnalitycs
Дашборд трейдера

Веб-дашборд для анализа журнала торговых сделок: ключевые метрики
результативности, кривая капитала, разрезы по стратегиям и инструментам,
загрузка собственного журнала из CSV.

> Репозиторий реконструирован с нуля: исходный код отсутствовал
> (в истории git — только README), поэтому реализована полноценная
> структура проекта под заявленное назначение.

## Архитектура

```
.
├── Home.py                  # точка входа Streamlit (главная страница)
├── pages/
│   └── 1_Метрики.py         # подробные показатели торговой системы
├── nison_analytics/         # прикладная библиотека (без зависимости от UI)
│   ├── models.py            # доменная модель: Trade, TradeSide, TradeStatus
│   ├── metrics.py           # метрики: win rate, profit factor, drawdown и др.
│   ├── reports.py           # DataFrame-агрегация, импорт/экспорт CSV
│   └── sample_data.py       # детерминированные демо-данные (seed фиксирован)
├── tests/                   # pytest: модели, метрики, CSV round-trip
└── requirements.txt
```

Разделение слоёв: вся расчётная логика вынесена в пакет
`nison_analytics`, страницы Streamlit только отображают данные.
Это позволяет тестировать метрики без UI и переиспользовать расчёты.

## Быстрый старт

```bash
pip install -r requirements.txt
streamlit run Home.py
```

По умолчанию показываются демо-данные. В боковой панели можно загрузить
собственный CSV журнала сделок.

## Формат CSV

Обязательные колонки: `symbol, side (long/short), entry_price, qty, entry_time`.
Необязательные: `status (open/closed/cancelled), exit_price, exit_time,
commission, strategy, tags, note`. Даты — ISO-8601. Тот же формат
используется кнопкой «Скачать CSV» (round-trip покрыт тестами).

## Метрики

* Чистый P&L, Win Rate, Profit Factor, Payoff Ratio, Expectancy;
* кривая капитала и максимальная просадка (абсолютная и в %);
* средний выигрыш/убыток, лучшее/худшее сделки, комиссии;
* среднее время удержания позиции, P&L по месяцам;
* группировки по стратегии, инструменту и направлению.

## Тесты

```bash
python -m pytest tests -q
```

22 теста: валидация модели, корректность P&L лонгов/шортов,
расчёт метрик, просадки, CSV импорт/экспорт.
