# Nison Analytics - Профессиональный дашборд для крипто-трейдинга

Профессиональный дашборд для технического анализа криптовалют на основе методологии Стива Нисона.

## 🚀 Возможности

### 📊 Обзор рынка по методологии Нисона

Дашборд построен в соответствии с принципами Стива Нисона:

**1. Контекст рынка**
- Режим рынка (ВОСХОДЯЩИЙ/НИСХОДЯЩИЙ/БОКОВИК)
- Определение тренда на основе EMA 20/50/200
- Consensus Score (0-5) - сколько индикаторов согласны

**2. Паттерны с подтверждением**
- 30+ свечных паттернов по Нисону
- Автоматическое подтверждение следующей свечой
- Фильтрация по контексту (тренд, объём, уровни)
- Модификаторы: (У ПОДДЕРЖКИ), (ОБЪЁМ), (С ГЭПАМИ)

**3. Ключевые уровни S/R**
- ZoneVoter - голосование за зоны (свинги, MA, Фибоначчи, объёмы)
- Сильные зоны (≥3 голосов)
- Адаптивный tolerance для разных ценовых диапазонов

**4. Объёмный анализ**
- Сравнение текущего объёма со средним
- Визуальная индикация повышенного/пониженного объёма
- Объём как подтверждение движения

**5. Правило множества технических приёмов**
- Consensus Score показывает силу сигнала
- Минимум 3 независимых подтверждения для входа
- Уверенность в процентах

**Торговые сигналы:**
- Автоматическая генерация через SignalGenerator
- Фильтрация по R:R ≥ 2:1
- Расчёт стопов по экстремуму всей формации
- Расчёт целей по зонам S/R
- Качество сигнала (50-95%)

**Данные:**
- Реальные данные с Bybit API
- Автообновление каждую минуту
- 8 основных торговых пар

## 🎯 Структура дашборда

### Dashboard (Обзор рынка)

Каждая карточка показывает:
1. **Контекст** - тренд и режим рынка
2. **Цена** - актуальная цена с изменением за 24ч
3. **Consensus Score** - сила сигнала (0-5)
4. **Подтверждённые паттерны** - только подтверждённые паттерны
5. **Ключевые уровни** - поддержка и сопротивление
6. **Объём** - сравнение с средним

### Analysis (Детальный анализ)

Страница анализа построена в порядке приоритета Нисона:
1. **Контекст рынка** - режим, consensus, объём
2. **График** - свечной график с EMA
3. **Ключевые уровни S/R** - поддержка и сопротивление
4. **Паттерны** - с подтверждением и описаниями
5. **Торговые сигналы** - с расчётом стопов/целей
6. **Индикаторы** - RSI, MACD, сила тренда

## 📚 Методология Стива Нисона

Вся логика анализа основана на книгах Стива Нисона:
- "Японские свечи" (Japanese Candlestick Charting Techniques)
- "За гранью японских свечей" (Beyond Candlesticks)

### Ключевые принципы:

**1. Контекст важнее паттерна**
- Паттерны работают только в правильном контексте
- Сначала определяем тренд, потом ищем паттерны

**2. Подтверждение следующей свечой**
- Каждый паттерн должен быть подтверждён
- Без подтверждения паттерн не работает

**3. Объём подтверждает движение**
- Повышенный объём усиливает сигнал
- Низкий объём - слабость сигнала

**4. Правило множества технических приёмов**
- Минимум 3 независимых сигнала для входа
- Consensus Score показывает силу

**5. Стоп за экстремумом формации**
- Стоп-лосс за экстремумом ВСЕЙ формации
- Не за одной свечой, а за всей моделью

**6. Уровни S/R - ключевые точки**
- ZoneVoter определяет сильные зоны
- Вход только у сильных зон

### Пятисвечные (3)

### Шестисвечные (2)

## 🎯 SignalGenerator - Генерация торговых сигналов

### Приоритеты сигналов:

**1. Высокоприоритетные** (многокомпонентные)
- Утренняя/Вечерняя звезда
- Покинутый младенец
- Три звезды
- Башенная вершина/дно
- Три горы/реки
- Три метода
- Удержание на татами
- Лестничное дно
- Две взлетевшие вороны
- Тасуки

**2. Среднеприоритетные** (двухсвечные)
- Поглощения
- Просвет/завеса
- Семейство "шеи"
- Контратака
- Разделение
- Линия пояса
- Пинцеты

**3. Низкоприоритетные** (односвечные с условиями)
- Харами (только у уровня!)
- Харами-крест (только у уровня!)
- Молоты
- Повешенный/падающая звезда
- Спружинивание
- Доджи (с учётом частоты и контекста)

### Расчёт стопов и целей:

**Стоп-лосс:**
- По экстремуму всей формации (не одной свечи!)
- Для односвечных: за экстремумом сигнальной свечи
- Для двухсвечных: за экстремумом обеих свечей
- Для трёхсвечных: за экстремумом всех трёх свечей

**Цель:**
- По ближайшей сильной зоне S/R
- Минимальный R:R = 2:1
- Фильтрация сигналов с R:R < 2:1

**Качество сигнала:**
- Базовое качество от типа паттерна (50-75%)
- +15% за подтверждение следующей свечой
- +8% за повышенный объём
- +7% за нахождение у уровня
- +5% за модификаторы (у поддержки, с объёмом)
- +30% за комбо (2+ паттерна одновременно)

## 🚀 Определение начала тренда (8 признаков Нисона)

Система анализирует 8 независимых признаков для определения начала нового тренда:

1. **Свечные разворотные сигналы** (гл. 4-6) - молоты, звёзды, поглощения в экстремумах
2. **Пробой уровней на объёме** (гл. 7, 15) - подтверждение пробоя повышенным объёмом
3. **Полярность уровней** (гл. 11) - пробитое сопротивление становится поддержкой
4. **Незакрытые окна/гэпы** (гл. 7) - гэпы в направлении тренда
5. **Пересечения скользящих средних** (гл. 13) - золотой/мёртвый крест MA10/MA65
6. **Дивергенции RSI** (гл. 14) - расхождение цены и осциллятора
7. **Рост объёма/открытого интереса** (гл. 15) - подтверждение движения
8. **Спружинивание** (гл. 11) - ложный пробой с возвратом

**Требование:** минимум 3 голоса из 8 для подтверждения начала тренда.

## 🖥️ Перенос на VPS сервер

### Вариант 1: Статический хостинг (проще)

**Требования:**
- VPS с Ubuntu 20.04+ или Debian 11+
- Nginx
- Домен (опционально)

**Шаги:**

1. **Сборка проекта локально:**
```bash
npm run build
```

2. **Загрузка на сервер:**
```bash
ssh user@your-vps-ip
sudo mkdir -p /var/www/nison-analytics
sudo chown user:user /var/www/nison-analytics

scp -r dist/* user@your-vps-ip:/var/www/nison-analytics/
```

3. **Настройка Nginx:**
```bash
sudo nano /etc/nginx/sites-available/nison-analytics
```

```nginx
server {
    listen 80;
    server_name your-domain.com;
    
    root /var/www/nison-analytics;
    index index.html;
    
    location / {
        try_files $uri $uri/ /index.html;
    }
    
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
    
    gzip on;
    gzip_types text/plain text/css application/json application/javascript;
}
```

4. **Активация и SSL:**
```bash
sudo ln -s /etc/nginx/sites-available/nison-analytics /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx

sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d your-domain.com
```

### Вариант 2: Docker (рекомендуется)

**Dockerfile:**
```dockerfile
FROM node:18-alpine as builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

**Деплой:**
```bash
docker build -t nison-analytics .
docker run -d -p 80:80 --name nison-analytics nison-analytics
```
