# Nison Analytics - Профессиональный дашборд для крипто-трейдинга

Профессиональный дашборд для технического анализа криптовалют на основе методологии Стива Нисона.

## 🚀 Возможности

### 📊 Обзор рынка (Реальные данные с Bybit)
- Карточки всех торговых пар с **актуальной ценой** с Bybit API
- Изменение за 24 часа в реальном времени
- Определение тренда на основе EMA 20/50/200
- RSI (14) рассчитанный по формуле Wilder
- Объём торгов
- Обнаруженные свечные паттерны
- Автообновление каждую минуту

### 📈 Детальный анализ
- **Свечной график** с паттернами (TradingView Lightweight Charts)
- **EMA 20/50/200** - экспоненциальные скользящие средние
- **RSI (14)** - индекс относительной силы
- **MACD** - схождение/расхождение скользящих средних
- **Уровни поддержки/сопротивления** - на основе pivot points
- **Детекция 30+ свечных паттернов** по методологии Стива Нисона
- **SignalGenerator** - автоматическая генерация торговых сигналов с расчётом стопов и целей
- **Подтверждение паттернов** - проверка следующей свечой
- **Фильтрация по контексту** - учёт тренда и объёма
- **Consensus Score** - объединение всех индикаторов

### 🕯️ Распознаваемые паттерны (30+)

**Односвечные:**
- Молот, Несовершенный молот, Перевёрнутый молот
- Повешенный, Падающая звезда
- Доджи (стркоза, надгробие, обычный)
- Спружинивание

**Двухсвечные:**
- Бычье/Медвежье поглощение
- Харами, Харами-крест
- Пинцет (верх/низ)
- Завеса из тёмных облаков, Просвет в облаках
- Линия пояса (бычья/медвежья)
- Контратака, Разделение
- Семейство "шеи" (ниже шеи, на шее, толчок)

**Трёхсвечные:**
- Утренняя/Вечерняя звезда (включая доджи-звезду)
- Три белых солдата, Три чёрных вороны
- Отбитое наступление, Торможение
- Покинутый младенец
- Тасуки, Три звезды
- Две взлетевшие вороны
- Двойной толчок, Гэп смежных свечей

**Пятисвечные:**
- Восходящие/Нисходящие три метода
- Удержание на татами
- Лестничное дно

**Шестисвечные:**
- Башенная вершина, Башенное дно
- Гэп-игра

### 🎯 SignalGenerator - Генерация торговых сигналов

**Приоритеты сигналов:**
1. **Высокоприоритетные** - многокомпонентные паттерны (звёзды, башни, три метода)
2. **Среднеприоритетные** - двухсвечные паттерны (поглощения, харами, пинцеты)
3. **Низкоприоритетные** - односвечные паттерны (молоты, доджи) с условиями

**Расчёт стопов и целей:**
- Стоп-лосс по экстремуму всей формации (не одной свечи!)
- Цель по ближайшей сильной зоне поддержки/сопротивления
- R:R минимум 1.5:1
- Фильтрация сигналов с R:R < 2:1

**Качество сигнала:**
- Базовое качество от типа паттерна (50-75%)
- +15% за подтверждение следующей свечой
- +8% за повышенный объём
- +7% за нахождение у уровня
- +5% за модификаторы (у поддержки, с объёмом)
- +30% за комбо (2+ паттерна одновременно)

### 📖 Автоматические описания паттернов

Каждый паттерн сопровождается объяснением "в духе Нисона" с ссылками на главы книги:
- **Молот**: "Длинная нижняя тень и малое тело у верха диапазона: продавцов выкупили к закрытию — попытка нащупать дно (гл. 4)."
- **Бычье поглощение**: "Второе тело полностью перекрыло первое: инициатива перешла к новой стороне (гл. 4)."
- **Три белых солдата**: "Три белые свечи с растущими закрытиями в зоне низких цен: рынок набирает силу (гл. 7)."

## 🔧 Установка и запуск

### Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev
```

Frontend будет доступен по адресу: http://localhost:5173

**Важно:** Frontend работает автономно с реальными данными Bybit API. Python бэкенд не требуется для базового анализа.

### Сборка для продакшена

```bash
npm run build
```

## 📡 Источники данных

### Прямые запросы к Bybit API

Frontend напрямую обращается к Bybit API для получения:
- **Свечные данные** - `GET /v5/market/kline`
- **Тикеры 24h** - `GET /v5/market/tickers`

**Преимущества Bybit API:**
- ✅ Поддержка CORS - работает напрямую из браузера
- ✅ Не нужен прокси сервер
- ✅ Стабильное соединение
- ✅ Real-time обновления

## 📚 Методология

Вся логика анализа основана на книгах Стива Нисона:
- "Японские свечи" (Japanese Candlestick Charting Techniques)
- "За гранью японских свечей" (Beyond Candlesticks)

Ключевые принципы:
- Контекст важнее паттерна
- Подтверждение следующей свечой
- Стоп за экстремумом формации
- Правило множества технических приёмов

```
│   ├── trend_detection.ts # Определение тренда (8 признаков)

│   └── adapters.ts        # Адаптеры данных
├── App.tsx                # Маршрутизация
└── main.tsx               # Точка входа
```
